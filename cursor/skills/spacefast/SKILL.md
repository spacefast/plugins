# Publish your work

Use the connected Spacefast tools. When working in a checkout, preserve unrelated files and changes.

If a task requires an existing Space and its identity is unclear, call `choose_space`. Use the selected Space as the target. A selection does not approve publishing or other changes.

Read the MCP calls, approval, and work mode rules in [references.md](references.md) before a management operation.

1. Use the artifact the user wants to publish. Keep its intended destination and access settings.
2. Read **Publish** in [references.md](references.md). It covers this host's publish route, receipt, and verification.
3. Do not rebuild an existing Space from its served files. For a file or design change, follow the source workflow instead.
4. Return the live link and version link from the result. State whether the version is live or only ready.
5. For a requested preview, redirect, or GitHub workflow, read the matching section in [references.md](references.md).
