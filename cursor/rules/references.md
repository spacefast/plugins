# Spacefast task skills

Read the skill for the requested task and follow its reference.
Use that reference's calling convention, runtime limits, approval flow,
and verification steps before management work.

- [Import a design system](../skills/import-design-system/SKILL.md): Save branding, design tokens, component standards, writing guidelines, and asset references from user-provided material into a Spacefast team's design system.
- [Apply a design system](../skills/apply-design-system/SKILL.md): Apply a Spacefast team's saved design system to a new build or an explicitly requested source edit. Use its standards and brand assets in the real project, then verify the result.
- [Verify design application](../skills/verify-design-system/SKILL.md): Check a Spacefast source build or preview against its saved team design system, including visual and editorial results. Report deviations and fix them when the task includes corrections.
- [Update an existing design](../skills/update-design/SKILL.md): Bring a named existing Spacefast Space or linked project into alignment with the team's current saved design system. Update affected source and assets, verify the result, and follow the request's deployment intent.
- [Publish your work](../skills/spacefast/SKILL.md): Publish an existing website, app, report, or other artifact to Spacefast and verify its live link. Also use to read or manage team Memories and inspect team Skills. For changes to an existing Space's content or design, use edit-space.
- [Build a website](../skills/build-website/SKILL.md): Create and publish a new Spacefast website from a brief, such as a landing page, portfolio, report, or dashboard. Use when the user wants a new site. For an existing Space, use edit-space.
- [Update your site](../skills/edit-space/SKILL.md): Change the content, design, or source files of an existing Spacefast Space and apply visual review notes. Use for page text, styles, layout, or file edits. Do not use for unrelated local editing.
- [Share with the right people](../skills/share-space/SKILL.md): Change who can access a Spacefast Space or path. Use to make it public, keep it private, invite specific people, or create or revoke a share link. Publishing content is a separate task.
- [Find or connect a domain](../skills/custom-domain/SKILL.md): Find, check, and register domains through Spacefast forms. Connect a domain the user owns to a Space, check DNS and HTTPS, or move its website to Spacefast. Preserve the existing site until the new destination works.
- [Fix or restore a deployment](../skills/fix-deployment/SKILL.md): Diagnose a failed Spacefast build, publish, or live page. Apply a fix supported by logs, or restore a known-good version when requested. Use when a deployment fails, stalls, or breaks existing behavior.
