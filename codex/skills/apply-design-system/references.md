# Choose the connected Spacefast reference

Use the tools advertised by the Spacefast connection selected for this task. A tool from another server does not identify this connection's mode.

If that connection advertises `execute`, read [Full mode](references-full.md). If it advertises named operations such as `getBootstrap` and `getSpace`, read [Simple mode](references-simple.md). Read only the matching reference, including its MCP calls, approval, and work mode sections.

If neither surface is available, reconnect Spacefast before management work. Follow the connected server's instructions and schemas when they differ from a packaged example. Do not switch modes or connections to retry a denied action.
